# ipTIME Tracker for Home Assistant

ipTIME 공유기의 관리자 API에서 현재 접속 기기를 읽어 Home Assistant의
`device_tracker` 엔티티로 제공하는 커스텀 인테그레이션입니다.

신형 관리자 UI(Flutter 기반, `/cgi/service.cgi` JSON API)를 쓰는 ipTIME
공유기를 대상으로 합니다. 구형 CGI 관리자 페이지만 있는 아주 오래된 펌웨어는
지원하지 않습니다.

## 주요 기능

- 무선 2.4/5/6GHz 및 EasyMesh 위성 기기 접속자 통합
- 공유기가 보고하는 기기 이름 자동 인식 (이름 필드가 없으면 원본 응답을
  디버그 로그에 남겨 원인 파악을 도움)
- 세션 만료 감지 및 자동 재로그인, 연결 실패 시 1회 재시도
- 추적할 기기를 직접 고르는 선택형 등록 — 공유기에 연결된 기기가 자동으로
  전부 추적되지 않고, 통합구성요소 설정 화면에서 체크한 기기만 엔티티가
  생성됩니다
- WAN(인터넷) 포트의 물리 링크 상태/속도 — 인터넷이 안 될 때 ISP 쪽 문제인지
  구분하는 용도
- SSDP를 통한 ipTIME 공유기 자동 발견

`device_tracker`는 목록에서 사라진 뒤에도 180초(3분) 동안은 `home`으로
유지합니다(Wi-Fi 절전모드로 인한 순간적인 접속 끊김 때문에 재실 상태가
깜빡이는 것을 방지하기 위함이며, HA 자체의 예전 `device_tracker` 기본값과
동일합니다).

## 설치

1. HACS에서 사용자 정의 저장소를 추가합니다.
2. 저장소 URL에 `https://github.com/feteeve/iptimetracker`를 입력합니다.
3. 카테고리는 `Integration`을 선택합니다.
4. ipTIME Tracker를 다운로드한 뒤 Home Assistant를 재시작합니다.
5. 설정 → 기기 및 서비스 → 통합 구성요소 추가에서 `ipTIME Tracker`를 선택합니다.
6. 공유기 주소/관리자 아이디/비밀번호만 입력하면 등록이 끝납니다. 이 시점에는
   아직 아무 기기도 추적되지 않습니다.
7. 등록된 통합구성요소의 **설정(⚙️)** 버튼을 눌러 추적할 기기를 체크하세요.
   현재 접속 중인 기기가 `IP - MAC` / 기기이름 형태로 나열됩니다.

## 설정값

| 항목 | 설명 |
|---|---|
| 공유기 주소 | 관리자 페이지 IP/호스트와 필요한 경우 포트 (기본값 `192.168.0.1`) |
| 관리자 아이디 | 공유기 관리자 ID (기본값 `admin`) |
| 관리자 비밀번호 | 공유기 관리자 비밀번호 |

탐지 주기(30초), 외출 판단 유예 시간(180초), EasyMesh RSSI 기준(-90dBm)은
고정값이며 설정 화면에는 노출되지 않습니다.

추적할 기기는 통합 구성요소의 **설정** 버튼에서 언제든 다시 고를 수 있습니다.
체크 해제한 기기의 엔티티는 즉시 제거됩니다. 옵션 변경 시 해당 통합
구성요소만 다시 로드되며 Home Assistant 전체를 재시작할 필요는 없습니다.

## 생성되는 엔티티

- 선택한 기기별 `device_tracker` (`home` / `not_home`)
- `binary_sensor`: ipTIME 인터넷(WAN) 연결 — WAN 포트에 물리 링크가 없으면
  off (라우터가 아직 이 API를 지원 못 하면 off가 아니라 unavailable로 표시)
- `sensor`: ipTIME WAN 링크 속도 (Mbps)

## 주의사항

- Home Assistant에서 공유기 관리자 주소로 접속할 수 있어야 합니다.
- EasyMesh 환경에서는 컨트롤러(마스터) 공유기의 주소를 입력하세요.
- CAPTCHA가 활성화된 관리자 계정은 자동 로그인이 불가능합니다.
- 이 통합은 ipTIME의 공개 외부 API가 아니라 관리자 UI 내부 JSON API를
  읽습니다. 펌웨어 업데이트로 형식이 바뀌면 일부 정보가 일시적으로 누락될 수
  있습니다. 디버그 로그에는 응답 원문이나 실제 이름/IP/MAC을 남기지 않고
  필드명만 남겨 새 형식에 대응할 수 있게 합니다.
